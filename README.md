# 徐照淼 · Personal Site

个人职业展示与经历维护仓库。站点内容来自简历与 `content/` 目录的结构化记录。

## 本地预览

```bash
cd /Users/bernicerick/PythonProject/personal-site
python3 -m http.server 8080
```

浏览器打开 http://localhost:8080

## 目录

```
index.html          # 个人展示页
styles.css          # 样式
content/            # 可版本控制的经历原文（教育/工作）
docs/               # 域名与个人 IP 运营说明
```

## 发布

推荐用 **GitHub Pages**（Settings → Pages → Deploy from branch `main` / root）。
买好域名后，在仓库根目录加 `CNAME` 文件，并按 `docs/domain-plan.md` 配置 DNS。
