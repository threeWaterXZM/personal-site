# 个人 IP 运营骨架

目标：用「可检索的公开痕迹」把专业身份固定下来。

## 渠道

| 渠道 | 用途 | 下一步 |
|------|------|--------|
| 本站 + 自定义域名 | 主页 / 简历入口 | 域名绑定 GitHub Pages |
| GitHub | 代码、项目叙事、Issue 驱动的公开思考 | 固定仓库介绍、Pinned repos、用 Issue 记公开 roadmap |
| X | 短观点、行业观察、项目片段 | 绑定公开账号到本站 |
| LinkedIn | 职业网络与背书 | 完善经历，与本站/简历对齐 |

## GitHub Issue 用法（建议）

在本仓库开几个长期 Issue 作为公开看板，例如：

- `#personal-ip`：本周对外输出清单
- `#learning`：学习与复盘
- `#shipping`：要公开的项目进展

每条 Issue 保持可被外人读懂，避免私密信息。
